# Portfolio

Site statique (HTML, CSS, JavaScript vanilla) hébergé sur GitHub Pages.

## Structure

```
index.html      → page unique : nav, hero, about, projets, outside school, skills, footer/contact
style.css       → styles (variables en haut du fichier)
script.js       → menu mobile, apparition au scroll, année du footer
assets/img/     → images
assets/docs/    → CV (cv.pdf)
```

## Lancer en local

```bash
python3 -m http.server 8000
# puis ouvrir http://localhost:8000
```
